# help · cómo usar la ayuda

## Uso
$ ./itc help                       índice: comandos y guías
$ ./itc help <comando>             ayuda de un comando (también: ./itc <comando> --help)
$ ./itc help <tema>                guía completa (nueva-instancia, actualizar, ...)
$ ./itc help variable <NOMBRE>     qué significa una variable de los .env
$ ./itc help variable              todas las variables, por archivo
$ ./itc help buscar <texto>        busca un texto en toda la ayuda
$ ./itc help temas                 solo la lista de guías

## Consejo
Si no sabes por dónde empezar: `./itc help nueva-instancia`. Si algo falló: `./itc help solucion-problemas`.
