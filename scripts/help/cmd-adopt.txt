# adopt · marcar una instancia que ya tiene datos

No siembra nada: solo deja el marcador `.initialized` (origen `existing`) para que `./itc init`
se niegue a ejecutarse sobre una instancia cuyas bases ya tienen datos reales.

## Uso
$ ./itc adopt <instancia>

## Cuándo usarlo
- la municipalidad ya funcionaba con PM2 y ahora la mueves a Docker apuntando a sus mismas bases
- `init` se detuvo porque las bases ya tenían datos

## Qué NO hace
- no modifica las bases de datos
- no levanta ni detiene contenedores

## Relacionado
- `./itc help instancia-existente`
- `./itc help datos`
