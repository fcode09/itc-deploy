# images · versiones de imagen disponibles

Lista las imágenes cargadas en este Docker por servicio y qué instancias las usan.
Solo lista: nunca borra nada. Alias: `./itc versions`.

## Uso
$ ./itc images [servicio] [--json]

## Cómo leer la tabla
- `im-uno(actual)` la etiqueta la usa esa instancia ahora
- `im-uno(previa)` es la versión anterior guardada para rollback
- `sin uso (candidata a borrar)` ninguna instancia la usa

## Opciones
- `servicio` muestra solo `s0` o solo `s1`
- `--json` salida para scripts (sin colores)

## Ejemplos
$ ./itc images
$ ./itc images s1 --json

## Relacionado
- `./itc help imagenes`, `./itc help actualizar`
